# Tushar Bhatt | Portfolio

A premium, interactive portfolio website showcasing my work, skills, and certificates.

## 🚀 Features

- **Dynamic 3D Background**: Powered by Three.js.
- **Interactive Project Showcase**: A custom carousel displaying selected projects.
- **Micro-animations**: Smooth transitions using GSAP.
- **Responsive Design**: Optimized for all devices.
- **Glassmorphic UI**: Modern aesthetic with blur effects and gradients.

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Libraries**: 
  - [Three.js](https://threejs.org/) for 3D graphics.
  - [GSAP](https://greensock.com/gsap/) for high-performance animations.
- **Fonts**: Space Grotesk, Inter.

## 📁 Projects

- **RetirePRO**: Professional Recruitment Platform with AI resume analysis.
- **ISLbridge**: Real-Time Sign Language Translating Platform.
- **BotForge**: AI Assistant Builder for Websites.
- **JARVIS**: Local AI Assistant (Offline).

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/tusharbhatt-24/my-portfolio.git
   ```
2. Open `index.html` in your browser or use a live server.
